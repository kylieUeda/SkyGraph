# Note
## Tools/Systems
### OCR - Optical Character Recognition
technology that converts different types of documents into editable and searchable data

### FastAPI
A simplified web server built with Python. Work like a bridge between python and the browser.

### CDN (Content Delivery Network)
a geographically distributed group of services that caches content - such as images, videos, and html files - closer to end-users to speed up website loading times.
画像や動画、HTMLファイルなどのコンテンツを世界中に配置されたキャッシュサーバーから配信することで、高速化、元サーバーの負荷軽減、セキュリティ向上、一部のサーバーがダウンした時にも保たれる安定性を実現する仕組み。インターネット上から直接読み込むため、インストール不要。
